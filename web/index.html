How it's built

Team Catalysts · UN SDG 4 (Targets 4.4 & 4.a)

The model

A logistic regression reads the message (TF-IDF over 25,000 words and phrases), alongside 23 red-flag detectors for urgency, threats, password requests, impersonation, money bait, job scams and more. A gradient-boosted tree model scores each link from 25 structural features. SHAP values turn every decision into named red flags. The message content leads; the sender address only nudges the score.

The data

  • Phishing & scams: Nazario corpus, advance-fee fraud, SMS scams, PhishTank URLs
  • Legitimate: SpamAssassin, Enron, CEAS, Ling, casual SMS
  • Campus & modern examples generated from the lures on campus

How well it works

  • Held-out test (1,768 messages): 97.4% recall, 0.6% false alarms, F1 0.98
  • Blind test of modern scams & everyday mail: 22 of 22 scams caught, 1 of 18 legit flagged
  • Python and browser engines agree on 924/924 test messages
